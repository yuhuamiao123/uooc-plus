## 功能特性

### 播放

| 功能 | 说明 |
|---|---|
| 2 倍速 | 唯一实测能稳定打勾的档位。**2.5x 以上会被平台判无效观看**，所以锁死在 2x |
| 自动静音 | 避免切到别的窗口时出声 |
| 自动播放 | 播放器就绪后自动开始，不需要点 |
| 失焦不断播 | 切到别的窗口 / 最小化时不会暂停 |

### 连播

| 功能 | 说明 |
|---|---|
| 三层目录递归下钻 | 章 → 节 → 子节 → 资源，层数不设死 |
| 跨节 / 跨章 | 一节播完自动进下一节，一章走完自动进下一章 |
| 自动跳过非视频 | 作业 / 测验 / 讨论 / 文档按标题关键词筛掉，不会点进去 |
| 播放结束即时记录位置 | 平台卸载播放器前先把"我播到哪"存下来 |
| 空态自愈 | 停在「请选择学习资源」的空白页时，5 秒内自动往下推一次 |

### 弹题

视频中弹出的确认题（防挂机用），从页面 Angular scope 里读取平台下发的 `quiz` 数据自动作答。

> 章节测验和期末考试**不在**自动作答范围内，需要自己处理。

### AI 答题（可选）

章节测验可以用大模型作答，支持任何 OpenAI 兼容接口（DeepSeek / 智谱 / 火山引擎等）。不配 Key 时其余功能照常可用。

### 其它

- **进度统计悬浮窗**：整个课程的视频 / 测验 / 讨论完成情况
- **卡死看门狗**：视频连续 6 分钟不再前进时，红色横幅 + 系统通知告警
- **非阻塞提示**：所有提示都是页面内浮层，不会像 `alert()` 那样冻住整个页面
- **遇智能验证暂停**：提交试卷时弹人机验证，脚本会停下来等人，不会硬闯

## 环境要求

- **Microsoft Edge 或 Chrome，版本 ≥ 111**
  低于这个版本不支持 `content_scripts` 的 `world: "MAIN"`，脚本会拿不到页面里的 `videojs` 和 Angular scope，弹题与部分播放控制会失效。
- 无需 Node.js、无需 Tampermonkey。

## 安装

本项目是**未打包的 MV3 扩展**，直接加载即可。

1. 把整个仓库下载到本地（`Code` → `Download ZIP`，解压）
2. 打开 `edge://extensions/`（Chrome 是 `chrome://extensions/`）
3. 左下角打开 **开发人员模式 / 开发者模式**
4. 点 **加载解压缩的扩展 / 加载已解压的扩展程序**
5. 选择仓库根目录（含 `manifest.json` 的那一层）

列表里出现 **UOOC 助手 Plus 3.4.6** 就装好了。

### 更新

替换 `uooc-plus.js` 后，回到扩展页面点卡片上的**刷新图标**，再回课程页 `F5`。

## 配置

只有 AI 答题需要配置，其余开箱即用。

课程页顶栏点 **⚙️**，填三项：

| 字段 | 说明 |
|---|---|
| API Base URL | DeepSeek `https://api.deepseek.com/v1`；智谱 `https://open.bigmodel.cn/api/paas/v4`；火山引擎 `https://ark.cn-beijing.volces.com/api/v3` |
| API Key | 对应平台控制台生成 |
| 模型名称 | 填平台控制台里的实际模型 id，例如 `deepseek-chat`。**不要填厂商名** |

「启用图片题目支持」只有在模型本身支持视觉时才勾。

填完勾上顶栏的 `LLM答题`，否则不会自动答。

### 配置存储在哪

`localStorage` 的 `llm_config` 键。卸载扩展即清除，不会外传。

## 使用

打开任意课程学习页，右上角会出现控制条：

| 开关 | 作用 |
|---|---|
| 2倍速 | 锁 2x |
| 静音 | 自动静音 |
| 播放 | 自动播放 / 暂停后自动恢复 |
| **全自动** | **连播总开关**。不勾就不会自动跳下一个 |
| LLM答题 | AI 作答章节测验 |
| 自动提交 | 填完答案后自动提交（建议先关着，人工检查一遍） |
| ⚙️ | AI 配置 |
| 📊 | 课程进度统计 |

勾上「全自动」后就不用管了。

### 三个调试命令

课程页按 `F12` 打开控制台：

```js
__uoocSelfCheck()   // 当前状态快照：版本 / 页面版本 / 目录行数 / 当前行 / 倍速 / 进度
__uoocDump()        // 把目录里所有资源项的 class 和文本摊开，连播卡住时先跑这个
__uoocAdvance()     // 手动触发一次"跳到下一个"，不用等视频播完
```

## 工作原理

### 注入方式

`manifest.json` 用 MV3 的 `content_scripts`：

```json
{
  "matches": ["https://*.uooc.net.cn/home/*", "https://*.uooc.net.cn/exam/*"],
  "js": ["uooc-plus.js"],
  "run_at": "document_idle",
  "world": "MAIN"
}
```

`world: "MAIN"` 是关键。默认的 isolated world 里读不到页面自己的 `window.videojs` 和 Angular `scope()`，而弹题答案藏在后者的数据结构里。

### 新版学习页的目录结构

2026 年优课改版后，学习页地址变成：

```
https://www.uooc.net.cn/home/learn/new/<课程id>#/<课程id>/<章id>/<节id>[/<资源id>]/section
```

目录 DOM：

```html
ul.newlearn_left_card_chapter_list
  li                                   章
    div.level_1_title#id_<章id>
    ul.level_2
      li                               节（可以再往下挂 ul.level_3）
        div.level_2_title#id_<节id>
        ul.level_3
          li                           子节
            div.level_3_title#id_<子节id>
            div.level_2_resourcelist        资源列表，只有展开的节点才渲染
              div.level_2_resourcelist_item[.active]
                span.level_2_resourcelist_item_text
```

四条踩出来的结论：

1. **资源项的层级前缀会跟着目录深度变**（`level_2_resourcelist_item` / `level_3_...`），写死前缀会漏。
2. **点标题只是"展开 + 导航"**，页面会停在「进入 X，请选择学习资源」的空白态，**不会自动播放**，必须再点一次具体的资源项。
3. **换章换节时旧节点会被整片销毁**，元素引用全部失效，位置只能用 id 记。
4. **路由段数会变**：2 段（只到章）/ 3 段（到节）/ 5 段（到资源）。节 id 恒为第 3 段，第 4 段是资源 id。

### 当前位置解析（降级链）

找不到"我在哪"就没法"往后走"。按可靠性依次尝试：

| 顺序 | 依据 | 适用 |
|---|---|---|
| 1 | 目录里 `.active` 的那一项 | 正常播放中 |
| 2 | `ended` 触发瞬间记下的那一项 | 刚播完 |
| 3 | 上次点过的那一项 | SPA 重建后 |
| 4 | 记住的节 id → `#id_<节id>` | 换了节但节点还在 |
| 5 | 记住的章 id → 该章第一个节点 | 刚换章 |
| 6 | URL 第 3 段 → 节 id | 页面刷新后 |

### 连播决策流程

```
视频 ended
  → waitCurrentTaskDone（新版只等 1.5 秒给平台上报）
    → findNextVideo
      → isNewCatalog() ? advanceNewCourse() : 老逻辑
```

`advanceNewCourse()` 依次尝试：

1. 只定位到"章" → 播这一章第一个节点（不能跳过，否则第一个节点永远不播）
2. 同一节点里的下一个视频
3. `walkForward()`：同级兄弟 → 父级下一节 → 逐层往上，直到章级
4. 下一章：展开后在该章里找第一个可播节点

`tryNode()` 遇到未展开的中间节点时，会点开后**绕过防重入守卫**直接处理子级 —— 否则会把自己刚设的"已展开"标记当成重复点击挡掉。

### 视频卡死看门狗

每 15 秒采样一次 `currentTime`。连续 6 分钟没推进，且播放开关是开的、不在跳转中，就判定卡死，红色告警。

这一条解决的是最隐蔽的失败模式：**你以为它在刷，其实半小时前就停在第 128 秒了。**

## 注意事项

### 关于风险

1. **不要通宵刷完一学期**。平台后端看的是学习时长分布，不是你的脚本多隐蔽。一晚上刷完 20 个视频，数据整齐得不像人 —— 这是被查的最常见原因。
2. **一次只开一节课**。多标签页同时刷是最明显的异常特征。
3. **倍速别动**。锁死 2x 是有原因的，2.5x 以上平台判无效观看，白刷还留记录。

### 关于使用

1. **别切到后台标签页**。Edge 会挂起后台页的渲染，SPA 重建正好卡在这个时间窗，连播会断。
2. **作业 / 测验节点会中断连播**。这是设计使然：那些页面会把学习页整个替换掉，脚本只能停下来等你处理完再继续。
3. **弹题需要平台数据**。如果页面结构再改版，弹题可能答不了；答不了时会 dump 现场信息到控制台，可以据此修。
4. **章节测验和期末考试不代做**。配了 AI 也只负责"填"，不负责"对"。

## 故障排除

### 先跑诊断

```js
__uoocSelfCheck()
```

正常应该是：

| 字段 | 期望值 |
|---|---|
| 视频元素 | `有` |
| 视频js | `有` |
| 页面版本 | `新版 /home/learn/new` |
| 目录行数 | `≥ 1` |
| 当前行 | `[新版] 1.1...mp4` |
| 当前倍速 | `2x` |

### 常见现象

| 现象 | 原因 | 处理 |
|---|---|---|
| 右上角没有控制条 | 扩展没加载 / URL 不匹配 | 看控制台有没有 `[UOOC助手] v3.4.6 已加载` |
| `页面版本` 显示旧版 | 不在学习页，或在老版页面 | 确认地址含 `/home/learn/new/` |
| `目录行数` 为 0 | 目录还没渲染完 | 等几秒重跑；仍为 0 说明页面结构改了 |
| 播完不跳 | 下一个是作业/测验 | 正常，手动做完再连播 |
| 停在「请选择学习资源」 | 点开了节点但没选资源 | 5 秒自愈会推一次；日志看「页面停在空态」 |
| 日志一直刷「展开…」 | 子级没渲染出来 | 看后面有没有「下面没有可播视频（子级=? 资源=?）」 |
| 弹题没自动答 | 找不到 `quiz` 数据 | 日志会有 `[弹题现场]` dump，看 scope 字段里有什么 |
| 视频卡住不动 | 弹题没答 / 网络断 / 播放器异常 | 6 分钟后会红色告警；先看页面有没有弹题 |
| 跳转后 502 错误页 | 优课服务器抽风 | 脚本会重试 3 次，之后手动 `Ctrl+F5` |

### 日志太多

控制台 Filter 框输入 `UOOC助手` 只看脚本日志。

### 连播卡住的定位方法

1. `__uoocDump()` 看目录里到底有几个资源项、当前项是哪行
2. 看最后一条 `连播(新版)` 日志停在哪个阶段：
   - `当前位置 章=? 节=?` → 定位成功
   - `展开「…」` → 在点开节点
   - `下面没有可播视频（子级=N 资源=N）` → 展开后没找到内容
   - `重试后仍定位不到当前位置` → 六条降级链全失败
3. 把这三条发 issue

## 常见问题

**Q：会被检测出来吗？**

A：脚本本身不做任何伪装（不伪造鼠标轨迹、不绕验证码）。平台后端能看的学习行为特征——时长分布、进度上报间隔、答题正确率——脚本改不了。**低风险来自使用方式，不来自工具**：分散时间刷、一次一节课、别把学习时长压成一条直线。

**Q：为什么只支持 2 倍速？**

A：原版作者实测 2.5x 以上会被平台判为无效观看。这不是脚本的限制，是平台的下限。

**Q：视频播完了但没自动跳？**

A：先确认「全自动」勾了。勾了还不行，看控制台最后一条 `连播(新版)` 日志是什么。

**Q：章节测验能全自动过吗？**

A：不能保证。AI 答题的正确率取决于模型，选择题问题不大，名词解释 / 问答 / 论述基本靠运气。而且很多课测验重做会扣分或限制次数，答错比不答更糟。建议关掉「自动提交」，让 AI 只填、人工检查后再交。

**Q：能用 Tampermonkey 装吗？**

A：不能直接装。`uooc-plus.js` 是 MV3 content script，不是用户脚本，缺少 `@match` 等元数据，而且依赖 `world: "MAIN"`。要用油猴得自行改回原版格式。

**Q：为什么不用 `git clone` 一条命令装？**

A：未打包扩展必须由浏览器"加载已解压的扩展程序"注册，无法通过脚本代劳 —— 这是浏览器的安全设计。

**Q：卸载后残留什么？**

A：`localStorage` 里的 `llm_config`（课程页域下）。扩展本身删除即干净，不写注册表、不常驻进程。
